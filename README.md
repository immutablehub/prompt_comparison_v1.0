## Why a Prompt Registry?

A lot of developers underestimate how painful prompt versioning becomes at scale.

As prompts evolve, behavior changes.
Validation changes.
Outputs drift.
Entire workflows can silently break.

Even legendary systems programmers have warned about the long-term maintenance cost of unstable abstractions.

Prompt registries solve this by making prompts:
- versioned
- reusable
- reproducible
- shareable
- auditable

AI infrastructure needs the same rigor that source code already has.
